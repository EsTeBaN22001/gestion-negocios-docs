# Skill — Documentation

## Propósito

Mantener documentación sincronizada con código.

## Leer antes

- `AGENTS.md`
- documentación específica afectada.

## Actualizar cuando

- cambia una API;
- cambia una entidad;
- cambia una regla;
- cambia arquitectura;
- cambia configuración de ejecución;
- se completa un requisito académico.

## Regla

No documentar como terminado algo que no esté implementado y verificado.

## Progress

Actualizar:

`docs/13-progress.md`

después de trabajo significativo.

## ADR

Crear/modificar un ADR cuando exista una decisión arquitectónica importante.

No crear ADRs para decisiones triviales.
