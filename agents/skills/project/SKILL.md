# Skill — Project Management

## Propósito

Coordinar trabajo general del proyecto sin modificar arquitectura innecesariamente.

## Antes de trabajar

Leer:

- `AGENTS.md`
- `docs/00-project-overview.md`
- `docs/01-requirements.md`
- `docs/02-business-rules.md`
- `docs/03-architecture.md`
- `docs/13-progress.md`

## Reglas

- Mantener el alcance.
- No agregar funcionalidades no solicitadas.
- Revisar código existente antes de crear archivos.
- Preferir reutilización.
- Mantener cambios pequeños.
- Actualizar documentación cuando cambie comportamiento.

## Decisiones

Si una decisión afecta:

- arquitectura;
- base de datos;
- seguridad;
- contrato API;

consultar antes de modificarla.

## Finalización

Informar:

- cambios;
- archivos afectados;
- pruebas;
- documentación actualizada;
- pendientes.
