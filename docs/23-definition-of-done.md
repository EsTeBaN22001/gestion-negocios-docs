# 23 — Definition of Done

Una funcionalidad no se considera terminada solamente porque "el código existe".

## Código

- [ ] Código implementado.
- [ ] Sigue la arquitectura.
- [ ] No hay duplicación innecesaria.
- [ ] No hay dependencias innecesarias.

## Backend

- [ ] Compila.
- [ ] DTOs correctos.
- [ ] Service correcto.
- [ ] Controller correcto.
- [ ] Validaciones.
- [ ] Autorización.
- [ ] Filtro de sucursal.
- [ ] Errores HTTP adecuados.

## Database

- [ ] Modelo correcto.
- [ ] Relaciones correctas.
- [ ] Migración creada si corresponde.
- [ ] Migración probada.
- [ ] Constraints correctos.

## Frontend

- [ ] Compila.
- [ ] Standalone.
- [ ] Reactive Forms si corresponde.
- [ ] Bootstrap.
- [ ] Service HTTP.
- [ ] Manejo de errores.
- [ ] JWT/interceptor si corresponde.

## Negocio

- [ ] Reglas implementadas.
- [ ] Casos inválidos probados.
- [ ] Permisos probados.

## Testing

- [ ] Flujo principal probado.
- [ ] Casos de error relevantes probados.

## Documentación

- [ ] Documentación actualizada.
- [ ] Progress actualizado.
- [ ] Requisito académico marcado si corresponde.

## Git

- [ ] Cambios revisados.
- [ ] Sin secretos.
- [ ] Commit claro.
