# ADR-007 — Docker First

## Estado

Aceptado.

## Decisión

Docker y Docker Compose estarán disponibles desde el inicio.

El proyecto también debe poder ejecutarse localmente sin Docker.

## Motivo

Docker facilita disponer de un entorno reproducible para MySQL y posteriormente para backend/frontend.

## Consecuencia

La configuración debe documentar ambos modos de ejecución.
